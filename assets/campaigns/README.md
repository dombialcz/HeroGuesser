# Campaign emblems

Created with the built-in image_gen tool on 29 October 2026 for Guild of Wits.
Exact prompts and generated source paths are in GENERATED_EMBLEMS.json.

- four-hidden-formations-v1.webp: four fanned parchment formation cards, blue stones and a guiding-star clasp for the Daily quests.
- cursed-bell-v1.webp: a cracked brass bell, walnut crossbar, thorn branches and a spectral blue wisp for The Cursed Bell story campaign.

Both are transparent illustrated emblems with blank blue ribbons. Titles remain live EN/PL HTML; the art carries no essential instructions and is hidden from assistive technology. Home containers own all dimensions, so failed/missing art cannot shift the controls. Gameplay character portraits remain unchanged.

Original transparent PNGs are preserved in ../../art-source/campaigns/. Runtime WebP exports fit within 640×640 at quality 90 with alpha retained. Source files and exact generation prompts are preserved; no generation-service dependency is needed at runtime.
