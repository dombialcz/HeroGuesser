Privacy / Prywatność

Development policy · 25 October 2026. The publisher contact will be finalized before App Store submission.

Local game data

The game stores your language, daily attempts and unfinished chapter progress in your browser, or in app preferences on iPhone. There is no account, analytics SDK, advertising, tracking, billing or cloud synchronization. Device or browser backup services may include this local data.

Daily saves older than 90 days are removed when the game checks the date. Chapter saves and language remain until you reset them, clear browser/app data or uninstall the app. Settings lets you reset stories, dailies or all game data separately. The tutorial is temporary.

Network and sharing

Core iPhone gameplay uses bundled content and fonts and works offline. The website is hosted on GitHub Pages; requests to load the website are handled by GitHub. Opening support/privacy links contacts that website. Sharing happens only when you press Share result; the selected app receives the result text, which includes the date, difficulty and feedback totals, without hero arrangements.

If you report an issue through GitHub, your report is handled by GitHub and may be public. Do not include private information. GitHub privacy statement.

Contact and updates

During development, use the project issue tracker. A publisher contact will be added before store release. This page must be reviewed whenever network services or SDKs change.

Lokalne dane gry

Gra zapisuje język, codzienne próby i postęp przygód w przeglądarce albo w ustawieniach aplikacji na iPhonie. Nie ma kont, analityki, reklam, śledzenia, płatności ani synchronizacji w chmurze. Kopie zapasowe urządzenia lub przeglądarki mogą zawierać te dane.

Zapisy codziennych zagadek starsze niż 90 dni są usuwane przy sprawdzaniu daty. Przygody i język pozostają do wyczyszczenia danych, resetu lub odinstalowania aplikacji. W Ustawieniach można osobno usunąć przygody, codzienne zagadki albo wszystkie dane gry. Samouczek jest tymczasowy.

Sieć i udostępnianie

Aplikacja iPhone zawiera treść i czcionki potrzebne do gry bez internetu. Strona jest utrzymywana przez GitHub Pages; GitHub obsługuje żądania jej wczytania. Otwarcie pomocy lub polityki prywatności łączy się ze stroną. Udostępnianie następuje tylko po naciśnięciu przycisku. Wybrana aplikacja otrzymuje datę, poziom i łączne wyniki prób, bez układów bohaterów.

Zgłoszenia błędów w GitHub mogą być publiczne. Nie podawaj danych prywatnych. W okresie rozwoju kontakt odbywa się przez zgłoszenia projektu. Dane kontaktowe wydawcy zostaną dodane przed publikacją w sklepie.
